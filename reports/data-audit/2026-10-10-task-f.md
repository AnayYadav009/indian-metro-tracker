# Task F: All-city relation-member station retrieval

The pipeline's `node(r)` relation-member retrieval is now used by the shared
Overpass query for every onboarded city. `build-all.ts --force` was added and
used to force-refresh each city's Overpass cache before rebuilding the complete
dataset.

## Rebuild and network conditions

All 11 city builds passed city-level schema and relational validation. Several
Overpass mirrors returned transient 429/500/504 failures; the pipeline tried
the configured mirrors and used the existing cache only for Kolkata after all
mirrors failed. That fallback is explicitly reported by the pipeline and is
not treated as newly fetched data.

Generated data was rebuilt through the pipeline; no generated GeoJSON was
hand-edited.
