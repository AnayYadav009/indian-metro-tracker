# Task E: Delhi verification

## E1: Reference comparison

`data/reference/delhi.json` contains operational station counts and terminal names,
but does not contain authoritative station-name arrays. It is therefore not
possible to list every missing station by name against that file without
inventing an official reference list. The count-only comparison is:

| Line | Reference operational count | Final operational count | Difference |
|---|---:|---:|---:|
| Red | 29 | 23 | -6 |
| Violet | 34 | 26 | -8 |
| Blue (including Vaishali branch where assigned) | 58 | 49/50 | -8/-9 |

The pipeline trace found the following direct route-relation station-body
counts before proximity and override association:

| Line | Raw relation-member station bodies | Normalized | Final |
|---|---:|---:|---:|
| Red | 16 | 16 | 23 |
| Violet | 22 | 22 | 27 |
| Blue | 49 | 49 | 50 |

No name-level “missing from official reference” list is reported because the
reference file does not provide the names needed to make that claim. The
count differences are reference-data gaps, not evidence that all missing
stations were lost at one pipeline stage. Direct relation-member bodies that
were absent in the raw response cannot be recovered by normalization; final
records also include proximity/override associations, so final counts are not
an equivalent comparison to the relation-member counts.
