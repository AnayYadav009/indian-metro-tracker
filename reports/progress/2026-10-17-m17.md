# M17 City Static Pages & SEO — 2026-10-17

Branch: `feat/m17-city-pages` (based on `master` at merge commit `fe7d425`).
Status: **Complete** (Branch kept unmerged per instructions).

This milestone implements static `/city/[id]/` pages for all 21 Indian metro networks in `data/cities.json` using `generateStaticParams`, fully compatible with Next.js static export (`output: 'export'`) and the GitHub Pages base path. Content is strictly grounded in compiled datasets (`data/cities.json`, `data/lines.json`, `data/segments.geojson`, `data/stations.geojson`, `data/reference/*.json`) with zero invented history or unsupported prose. Includes unique metadata, Schema.org JSON-LD structured data, static `sitemap.xml` and `robots.txt`, bidirectional navigation between map, compare, and city pages, home page crawlable links, unit tests, and Playwright E2E tests.

## Architectural Notes & Design Decisions

1. **Static Export Architecture**: All 21 city pages are pre-rendered at build time into `out/city/[id]/index.html` via `generateStaticParams()`. No server runtime or database is used, preserving 100% static hosting compatibility on GitHub Pages under any base path.
2. **Schema.org JSON-LD Restraint**: JSON-LD scripts are strictly restricted to verifiable data points: `ItemPage` with `mainEntity` of type `City`, its verified name, canonical URL, grounded description, and `GeoCoordinates` (`latitude`, `longitude`) computed from the exact bounding box midpoint of the city. Unverifiable fields (fares, schedules, telephone numbers) are strictly excluded.
3. **Transparent Factuality**: In accordance with project standards, no unsupported claims or invented historical prose are generated. Cities like Surat with zero operational stations clearly state that all corridors are under active construction; cities with unrecorded opening dates display a clean "—" indicator rather than guessing dates.
