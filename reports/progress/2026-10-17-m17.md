# M17 City Static Pages & SEO — 2026-10-17

Branch: `feat/m17-city-pages` (merged into `master`).
Status: **Complete & Merged into master**.

This milestone implements static `/city/[id]/` pages for all 21 Indian metro networks in `data/cities.json` using `generateStaticParams`, fully compatible with Next.js static export (`output: 'export'`) and the GitHub Pages base path. Content is strictly grounded in compiled datasets (`data/cities.json`, `data/lines.json`, `data/segments.geojson`, `data/stations.geojson`, `data/reference/*.json`) with zero invented history or unsupported prose. Includes unique metadata, Schema.org JSON-LD structured data, static `sitemap.xml` and `robots.txt`, bidirectional navigation between map, compare, and city pages, home page crawlable links, unit tests, and Playwright E2E tests.

## Acceptance Criteria & Fixes Summary

All acceptance criteria from `docs/MILESTONES-v2.md` and user instructions are met: **10/10 (100%)**.

| Criterion | Result | Evidence |
|---|---|---|
| **Static `/city/[id]/` route for all 21 cities using `generateStaticParams`** | **PASS** | `app/city/[id]/page.tsx` implements `generateStaticParams()` returning all 21 city IDs from `data/cities.json`. Generates 21 static HTML pages in `out/city/[id]/index.html` during `next build` export without runtime server dependencies. Compatible with `basePath`. |
| **Page content derived strictly from compiled data** | **PASS** | Metrics (operational km, construction km, planned km, total km, station counts, line counts, interchanges) and line details (status, terminals, operators, lengths, stations) are calculated directly from compiled GeoJSON vectors and reference records via `lib/city-page-data.ts`. No invented history or ungrounded prose. |
| **Opening-year range 80% threshold rule** | **PASS** | `openingYearRange` displays a year range (e.g. `2017 – 2024`) strictly when at least 80% of the city's stations have `opened_on` dates recorded. When `<80%` of stations are dated, displays `"Opening dates recorded for N of M stations"` instead of a range. Cities with zero dates display `"no dates recorded"`. In SEO descriptions, year clauses are only emitted if the 80% threshold is met, preventing misleading claims. |
| **Patna operational counts reconciliation** | **PASS** | Verified against compiled dataset: `data/stations.geojson` has 5 operational stations; `data/segments.geojson` has 1 operational segment (`pat-blue-seg-01`: 5.283 km rounded to 5.3 km); `data/reference/patna.json` declares 5 operational stations and 5.28 km. Both `/compare/` and `/city/patna/` display 5 operational stations and 5.3 operational km. There is 0 mismatch. |
| **Transparent handling of 0-operational cities (Surat)** | **PASS** | Cities with 0 operational stations (Surat: 0 operational stations, 37.1 km under construction) render a dedicated construction notice banner (`data-testid="zero-operational-notice"`) and state in the meta description and text that the network is actively under construction with 0 open stations. |
| **Data-completeness notices for coverage gaps & pending rules** | **PASS** | Cities with known coverage gaps or pending audit rules (e.g. Delhi, Bhopal, Chennai) display the existing plain-language caveat callout banner (`data-testid="completeness-caveat-banner"`) using `getKnownIssueNotice`. |
| **Unique `<title>`, description, canonical URL, OpenGraph, Twitter, and Schema.org JSON-LD** | **PASS** | `lib/city-seo.ts` generates unique `<title>`, grounded descriptions, canonical URLs pointing to `${SITE_CONFIG.siteUrl}/city/${city.id}/`, OpenGraph, and Twitter card tags. Injects valid Schema.org `ItemPage` with `mainEntity` of type `City` containing verified `name` and `url`. Per instructions, `GeoCoordinates` computed from bounding box midpoints are omitted. |
| **Static `sitemap.xml` and `robots.txt` matching deployed GitHub Pages URL** | **PASS** | `app/sitemap.ts` and `app/robots.ts` generate static `out/sitemap.xml` and `out/robots.txt` using `SITE_CONFIG.siteUrl` (`https://anayyadav009.github.io/indian-metro-tracker`), matching `.github/workflows/deploy.yml` and the deployed GitHub Pages URL. |
| **Deep linking & crawlable directory navigation** | **PASS** | City pages link directly to the interactive map (`/?city=[id]`) and `/compare/`. `/compare/` table rows link directly to `/city/[id]/`. The home page (`app/page.tsx`) contains a crawlable semantic `<nav aria-label="City Directory">` linking all 21 cities plus a header "Cities" modal. |
| **No unintended files committed** | **PASS** | `git show --stat` confirms only relevant milestone files are included in the branch. |
