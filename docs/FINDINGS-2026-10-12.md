## Hypotheses to test first (not findings)

- **H-1** The pipeline clips segments or stations to the city bounding box or to a Delhi-only Overpass area, which would explain F-01 at the NCR edge.
- **H-2** The audit did not catch F-01 because the Delhi reference file is missing, marked `confidence: unverified` (errors downgraded to warnings), lists only two terminals for the branched Blue Line, or the warning is baselined.
- **H-3** The existing duplicate-geometry rule requires overlap and misses offset twin tracks (F-07, F-10). The self-intersection rule misses spikes that double back without crossing (F-03).
- **H-4** Orphan and proximity rules may skip construction and planned stations, which would explain F-11.
- **H-5** Golden Line was removed from lines.json on 2026-10-08 because it had no segments; it needs onboarding as a construction corridor, not a bug fix.
